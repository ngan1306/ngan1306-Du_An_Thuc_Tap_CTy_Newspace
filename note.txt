Dưới đây là hướng dẫn chi tiết cách chạy ứng dụng:

## 📋 Yêu Cầu Cơ Bản
- Node.js (v14+)
- Python 3.8+
- PostgreSQL (hoặc dùng mock data)
- VS Code hoặc terminal

## 🚀 Cách Chạy Ứng Dụng

### **Bước 1: Chuẩn Bị Frontend**

Mở terminal PowerShell, navigate đến folder frontend:

```powershell
cd d:\ThucTap\du_an_truong\frontend
```

Cài đặt dependencies:

```powershell
npm install
```

### **Bước 2: Chuẩn Bị Backend**

Mở terminal PowerShell mới, navigate đến folder backend:

```powershell
cd d:\ThucTap\du_an_truong\backend
```

Tạo virtual environment Python:

```powershell
python -m venv venv
```

Kích hoạt virtual environment:

```powershell
.\venv\Scripts\Activate.ps1
```

Cài đặt dependencies:

```powershell
pip install -r requirements.txt
```

### **Bước 3: Chạy Backend**

Trong terminal backend (virtual environment đã kích hoạt):

```powershell
python app.py
```

Backend sẽ chạy tại: **http://localhost:5000**

### **Bước 4: Chạy Frontend**

Trong terminal frontend:

```powershell
npm start
```

Frontend sẽ mở tại: **http://localhost:3000**
